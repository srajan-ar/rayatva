# Rayatva

A premium learning and growth platform focused on certified courses, live yoga sessions, and business growth services.

## Stack
- Next.js 14
- React 18
- TypeScript
- Responsive landing page experience

## Run locally

```bash
cd Web
npm install
npm run dev
```

## Production build

```bash
cd Web
npm run build
npm run start
```

## Features
- cinematic landing page
- responsive mobile-first design
- auth and booking interaction flows
- dashboard and course entry points
- SEO-ready metadata, sitemap and robots configuration
