# Rayatva

Rayatva is a premium learning and growth platform designed to help people build stronger skills, healthier routines, and more impactful businesses. The experience blends expert-led online learning, live wellness programs, and business growth services into one modern ecosystem.

Built as a polished ed-tech and lifestyle brand experience, Rayatva brings together:
- certified learning tracks
- live yoga and wellness sessions
- business growth and brand strategy support
- personal development for founders, creators, and learners

## Why Rayatva

Rayatva is more than a course website. It is a growth ecosystem for ambitious people who want to learn, improve, and build with intention.

The platform is designed to help users:
- upgrade practical business and creative skills
- cultivate consistency through wellness routines
- access structured learning with trackable progress
- connect with a brand experience that feels premium and trustworthy

## Product Vision

Rayatva blends three core pillars:

1. Learning

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18 or newer
- npm

### Install dependencies

```bash
cd Web
npm install
```

### Run the app locally

```bash
cd Web
npm run dev
```

Then open:

```text
http://localhost:3000
```

If port 3000 is occupied, Next.js will automatically try the next available port.

## Production Build

```bash
cd Web
npm run build
npm run start
```

## Deployment Notes

This project is built for a modern web deployment environment compatible with platforms like:
- Vercel
- Netlify
- custom Node-based hosting providers

For deployment, the recommended approach is to deploy the frontend from the `Web` directory as a Next.js app.
